# StateApi and DataApi regression ledger

This ledger began as a comparison of pull request #381 at historical head
`02a5099091c020917ee9bec1caae4ffad9b59e25` with its original
`e89cb4acdaf16e8b7d962b2a14d6df95916c8520` base. The rows are maintained
through later amendments and classify the code at the current pull request
head; a green test suite or aggregate coverage percentage is not treated as
evidence by itself. The synchronous failure rows follow the explicit PR #470
scope correction: retain ordinary cleanup and the Region restoration-listener fix;
constructor/subscription rollback and recovery after throwing callbacks are not
accepted contracts. See the [public failure boundary](../docs/view.lifecycle.md#synchronous-failures).
