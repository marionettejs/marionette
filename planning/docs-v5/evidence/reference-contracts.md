# Reference contract source checks

Inspected 2026-09-28 against source HEAD `b6f23c5953793d5cef1cb51dbc675420214ffd01`. This is a source audit supporting the API references. The linked tests were read, not rerun for this audit; package probes do not prove every reference statement.

| Contract | Exact source meaning | Source and supporting tests |
| --- | --- | --- |
| `Model.reset(attributes)` restores defaults | Builds `{ ...getDefaults(this), ...attributes }`, removes current keys absent from that result, then uses normal change notification. Supplied attributes override defaults. `reset()` uses empty attributes. It does not run on a destroyed Model. | [Model.reset](../../../packages/data/src/model.ts#L168), [getDefaults](../../../packages/data/src/model.ts#L73). Tests cover [reset/change events](../../../test/unit/data-package/model.spec.js#L47), [construction defaults](../../../test/unit/data-package/model.spec.js#L5), and [destroyed reset skipping defaults](../../../test/unit/data-package/model.spec.js#L259). The specific reset-plus-defaults merge is verified directly in source. |
| `Collection.get(identity)` accepts a Model, id, or cid | Returns an exact member Model first; otherwise matches a model id using SameValueZero, then a cid. Null/undefined return undefined. It does not resolve an arbitrary attributes object by reading its `id`. | [Collection.get](../../../packages/data/src/collection.ts#L219); [identity/id/cid precedence](../../../test/unit/data-package/collection.spec.js#L133), [NaN id lookup](../../../test/unit/data-package/collection.spec.js#L193). |
| Re-rendering a View cleans child Views | An already-rendered View with a template calls `_reInitRegions`; each Region is **reset**, not destroyed. Reset empties and destroys its current child, then restores the initial element reference. `template: false` returns before this work. | [View.render](../../../src/modules/view.ts#L527), [_reInitRegions](../../../src/modules/view.ts#L307), [Region.reset](../../../src/modules/region.ts#L482), [Region.empty](../../../src/modules/region.ts#L364). [Re-render tests](../../../test/unit/view.child-views.spec.js#L420) verify Region emptying/rebinding; destruction follows the source's `empty` path. |
| `Application.showView` works while stopped | Requires a destination Region when a root exists, but checks terminal lifetime rather than running state. It displays/tracks the root without activating the Application. A later stop destroys that root even when already stopped. | [Application.showView](../../../src/modules/application.ts#L840), [stopped stop cleanup](../../../src/modules/application.ts#L662); [stopped root test](../../../test/unit/application-root-view.spec.js#L257). |
| Application `stateEvents` can deliver during pending stop preparation | Delivery uses `_isRunning`. A running Application stays active while stop preparation is pending; successful stop sets running false before emptying its root. This is not a blanket “no events after calling stop” rule. | [state-event gate](../../../src/modules/application.ts#L200), [stop deactivation](../../../src/modules/application.ts#L582); [pending-stop event test](../../../test/unit/application-state-events.spec.js#L40). |
| DOM `triggers` prevent default and stop propagation | Both behaviors default to enabled. An object trigger definition can disable each with literal `false`. Trigger arguments begin with the View and DOM event. | [buildViewTrigger](../../../src/mixins/view-events.ts#L33); [default behavior tests](../../../test/unit/view.triggers.spec.js#L124), [disabled behavior tests](../../../test/unit/view.triggers.spec.js#L146). |
| Repeated `start` with another Region rejects | During a pending or running start, an explicitly different Region fails compatibility and returns a rejected Promise with `MN0041`. It does not synchronously throw or silently ignore the destination. A compatible pending start shares its Promise; an already running start resolves true. | [Application.start](../../../src/modules/application.ts#L622); [running conflict test](../../../test/unit/application-start-region.spec.js#L71), [pending conflict test](../../../test/unit/application-start-region.spec.js#L82). |
| `@mnjs/data` owned state disposal | Its `StateApi.disposeOwned(source)` calls `source?.destroy?.()`. Marionette invokes disposal only for state created by the owner, after releasing that owner's state subscriptions. A supplied state source is borrowed; arbitrary fields such as `records` do not participate. | [data StateApi](../../../packages/data/src/api.ts#L23), [Marionette state cleanup](../../../src/mixins/state.ts#L68); [native adapter disposal test](../../../test/unit/data-package/api-integration.spec.js#L199), [borrowed source test](../../../test/unit/state-owner.spec.js#L94), [owned cleanup ordering test](../../../test/unit/state-owner.spec.js#L119). |
