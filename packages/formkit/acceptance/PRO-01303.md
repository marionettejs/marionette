# Pro 0.130.3 release assessment — 2026-11-03

This assessment accompanies the master-based integration branch. It does not
replace the earlier versioned 0.130.1/0.130.2 receipts or extend their results to
new source or Pro versions. Adapter production code is unchanged by this update.

## Verified package delta

Official registry metadata reports 0.130.3 published at **14:28:25.746 UTC** on
November 3. Both official archives were downloaded and matched against their
registry SHA-512 integrities; exact metadata and file hashes are in
[pro-01303/](pro-01303/).

Only `index.mjs`, `index.cjs` and the package version changed among 35 files. Each
root bundle grew 463 bytes. Dependencies, peer dependencies, exports, declarations,
README, CSS, license and control-subdirectory files are unchanged. No package
changelog was added. The public changelog view retrieved for this assessment did
not expose a 0.130.3 entry, and the registry git-head comparison returned 404 on
public GitHub; no separate upstream release-note claims are asserted here.

Independent static review of the bundles identified two changes:

- Active-option scrolling avoids pointer-hover tracking and repeated scrolling to
  the same active descendant. Per-node tracking resets on close.
- Open popovers observe height changes and refresh positioning/inversion when the
  height differs. Observers disconnect on close/destruction and resume on reopen.
  The shared feature serves dropdown, autocomplete, datepicker, taglist and colorpicker.

The root ESM/CJS imports remain FormKit utils/core/inputs, drag-and-drop and tempo.
Neither version has the earlier undeclared Vue import. A fresh installed graph,
ESM/CJS import and build check is still required for this fixture revision.
No adapter change is justified by the static delta alone.
