## Actual Pro mounting is still blocked

In all three real browser consumers, with `location.hostname === 'localhost'`,
the unmodified `createProPlugin(undefined, inputs)` call throws:

> A FormKit API key is required, please visit https://formkit.com/pro

This environment has no configured secret/runtime license binding or existing
licensed consumer. No new key was requested, no arbitrary key supplied, and no
premium definition registered around the plugin. The vendor's
[keyless-localhost statement](https://formkit.com/pro) and the observed bootstrap
outcome disagree. All 14 Pro controls remain unverified at the rendering stage:
autocomplete, dropdown, taglist, datepicker, colorpicker, currency, mask, unit,
slider, rating, repeater, toggle, togglebuttons, and transferlist.
