## Bounded behavior targets

The coordinator verified five claims in the official Pro changelog tab. Static
review confirmed corresponding code changes in both root formats:

- Currency display `none` uses currency-specific fraction digits with decimal
  presentation. Explicit precision options override the defaults.
- `showMask` updates the mounted mask's placeholder presentation without
  replaying input solely for that prop change.
- Options arriving after a selected value can replace missing-option selections
  and their cached labels in dropdown, autocomplete and taglist.
- Repeater dragging benefits from drag-and-drop's occurrence-aware handling of
  duplicate/replaced values. Pro's repeater implementation itself is unchanged.
- Transfer-list target search merges by option value rather than serializing
  complete option wrappers, avoiding their `toJSON` methods.

No adapter source change or Core upgrade is justified by static review alone.
The opt-in release fixture and eight-case collector exercise these boundaries
through public APIs. Real pointer dragging is required; move-up/down buttons do
not exercise the changed drag-and-drop dependency. Duplicate values are tested
in the genuine Pro repeater, not as duplicate Marionette RowView keys.
